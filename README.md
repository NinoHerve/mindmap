# MindMap 

Mindmap is a project encompassing the entirety of the code for my Ph.D. project entitled "Enhancing Electrical Source Imaging with Connectomics." In this project, I develop, improve, validate, and evaluate new source imaging methods that utilize informed priors based on connectivity research.

One of the limitations of source imaging is that information about the source covariances must be provided in order to accurately reconstruct brain activity from EEG or MEG. Some methods attempt to compute those covariances from fMRI data measured during the same task. However, neuronal and temporal mismatches complicate this data-driven approach. For this project, we use connectomics to infer the structural connections between sources and incorporate new research on functional-structural information to generate new priors, which provide indirect information about the source connectivities.

In this folder, you will find every piece of code I required to fulfill my Ph.D. objectives, as well as guidelines to obtain the results of my different studies.
